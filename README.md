# StudyMate AI

An AI study assistant built with FastAPI. It will chat, answer questions from PDFs, summarize text, and generate quizzes.

## Status
Milestone 1 complete: project setup and a running FastAPI backend.

## How to run
1. Create a virtual environment: `python -m venv venv`
2. Activate it: `venv\Scripts\activate`
3. Install libraries: `pip install -r requirements.txt`
4. Start the server: `uvicorn backend.main:app --reload`
